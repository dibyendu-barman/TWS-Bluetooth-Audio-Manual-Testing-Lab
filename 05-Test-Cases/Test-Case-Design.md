# Test Case Design Guidelines

## Objective

Define the approach used to design manual test cases for the TWS Bluetooth Audio Manual Testing Lab.

## Test Case Structure

Each test case contains:

- Test Case ID
- Requirement ID
- Module
- Test Type
- Scenario
- Title
- Priority
- Preconditions
- Test Data
- Steps
- Expected Result
- Actual Result
- Status
- Bug ID
- Evidence
- Remarks

## Design Techniques

The project uses:

- Positive testing
- Negative testing
- Boundary-oriented thinking
- State transition testing
- Recovery testing
- Exploratory testing
- Regression testing

## QA Principle

Test cases should be:

- Clear
- Reproducible
- Independent where practical
- Observable
- Traceable
- Maintainable
