# Audio Test Materials

## Purpose

This document defines the audio files and test signals used during manual TWS audio testing.

## Test Material Matrix

| ID | Test Material | Purpose |
|---|---|---|
| AUD-MAT-001 | Silence | Check background noise |
| AUD-MAT-002 | Voice | Check speech clarity |
| AUD-MAT-003 | Music | General playback |
| AUD-MAT-004 | Left-channel signal | Verify left channel |
| AUD-MAT-005 | Right-channel signal | Verify right channel |
| AUD-MAT-006 | 100 Hz tone | Low-frequency observation |
| AUD-MAT-007 | 1 kHz tone | Mid-frequency observation |
| AUD-MAT-008 | 10 kHz tone | High-frequency observation |

## File Information

Record:

- File name
- Format
- Sample rate
- Bit depth
- Duration
- Channel configuration

## Safety

Audio should be played at a comfortable listening level.

Avoid prolonged exposure to high volume.
